# Changelog

## 2.0.0

Expanded REST resource access, validated fluent parameters, corrected response formats and provider registration, Laravel test support, and complete documentation. See the [release notes and migration guide](docs/releases/2.0.0.md).

This is a major release because it declares Laravel 10–13 compatibility constraints and changes invalid-option and Check Access behavior.
